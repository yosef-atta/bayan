# Security Policy

## Supported Versions

Bayan is currently under active pre-release development.

No production release is currently supported. This section will be updated when Bayan publishes its first supported release.

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's **Private Vulnerability Reporting** / Security Advisories.

Do **not** open a public Issue or Discussion for an undisclosed vulnerability.

Include enough detail to reproduce and understand the issue, such as the affected component, expected and actual behavior, reproduction steps, and any relevant proof of concept.

## What to Report

Security reports may include:

- authentication or session bypasses
- OAuth vulnerabilities
- BYOK or API key exposure
- encryption or Fernet key handling issues
- secret leakage
- unauthorized access to user data or chat history
- SQL injection, command injection, XSS, CSRF, or similar application vulnerabilities
- dependency vulnerabilities with a concrete security impact on Bayan

Normal bugs without a security impact should be reported through GitHub Issues.

## Disclosure

Please keep vulnerability details private until the issue has been investigated and addressed.

Do not publicly disclose an unresolved vulnerability, reproduction details, or sensitive information without maintainer coordination.
